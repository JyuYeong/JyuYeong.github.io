지문 잠금 해제 테스트

패스키로 지문을 확인하고, 그때만 나오는 비밀값(PRF)으로 암호화 키를 꺼낼 수 있는지 확인합니다. 앱 데이터는 건드리지 않습니다.

결과: 아래 순서대로 눌러 주세요

0. 이 기기 환경

1. 테스트용 패스키 만들기

지문(PC는 Windows Hello)을 확인한 뒤 이 기기에 "PRF 테스트" 패스키를 만듭니다.

2. 지문으로 비밀값 받기 (2번 이상)

처음 누르면 비밀값으로 테스트 문장을 암호화해 둡니다. 다음부터는 같은 비밀값이 나오는지, 그 값으로 문장이 풀리는지 확인합니다. 페이지를 닫았다 다시 열어서 눌러 봐도 됩니다.

3. 기록

    이 버튼은 이 페이지의 기록만 지웁니다. 만든 패스키는 Google 비밀번호 관리자(PC는 Windows 설정 → 계정 → 패스키)에서 jyuyeong.github.io · prf-test를 직접 지우면 됩니다.
